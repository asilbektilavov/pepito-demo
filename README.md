# Бюджет месяца

Мини-приложение для контроля расходов: категории с бюджетом на месяц, списание трат и остаток в сумах.

- `index.html` — всё приложение в одном файле, без сборки. Если открыть его просто в браузере, данные хранятся только в этом браузере.
- Опубликованная версия в Claude хранит данные в общем хранилище, поэтому все, кому открыт доступ, видят одни и те же цифры.
